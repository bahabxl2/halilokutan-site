# Halil Okutan - Kişisel Web Sitesi

Halil Okutan'ın kişisel web sitesi ve portföyü.

## Başlangıç

Projeyi yerel olarak çalıştırmak için:

```bash
# Dosyaları klonla
git clone https://github.com/bahabxl2/halilokutan-site.git
cd halilokutan-site

# Web sunucusunu başlat
npm start
```

Tarayıcında `http://localhost:8000` adresine git.

## Proje Yapısı

```
halilokutan-site/
├── index.html          # Ana HTML dosyası
├── styles.css         # CSS stilleri
├── package.json       # npm yapılandırması
├── .gitignore         # Git yapılandırması
└── README.md          # Bu dosya
```
